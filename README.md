# Administrarcion-de-Empresas
El programa gestiona y analiza las ventas diarias de una empresa con 6 sedes durante una semana. Calcula promedios diarios y semanales, identifica días con ventas superiores a la media y ajusta un 15% las ventas inferiores a la media. Facilita la toma de decisiones estratégicas al mejorar la eficiencia y rentabilidad de las sedes.
